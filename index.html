kunye

A photo file can carry notes that usually stay out of sight: the device, the time, sometimes the place, and in some files a signed record saying whether a model made it. Drop a JPEG or PNG here to read them, see what they may and may not show, and save a copy without them.

The file is read on this device. This page blocks outgoing requests, so it should keep working offline once saved.

How to read the result

A missing note may say little. Many images seem to carry no signed record, and notes may be removed along the way when a file is shared. When a record is missing, the file alone gives no answer about how the picture was made.

A plain note is a hint. Device, software and labels in plain notes are easy to edit, so kunye shows them without treating them as proof.

A signed record may say less than it seems to. When its checks pass, the file has likely not changed since it was signed, and you can see what the signer declared. Whether that declaration is true, or whether the signer deserves trust, is hard to judge from the file alone.

What it does not do

It doesn't look at the pixels, so when a file has no notes it can't help tell a generated image from a photograph. It doesn't compare signers with a list of trusted ones. It reads JPEG and PNG only. A clean result means only that kunye found nothing it recognizes.
